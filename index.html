30 fps 프레임

검증 방법

  1. 30 fps 변환

    • 고속 영상에서 1/30초 간격의 프레임만 사용
    • 프레임 추출 위치를 바꿔 가며 타구당 –회 반복

  2. 공 검출

    • 포스터가 인용한 WASB [7]⁠를 추가 학습 없이 사용
    • 근접 촬영 영상은 모델 입력에 맞게 축소

  3. 타점 복원

    • 임팩트 전 4장, 후 3장의 공 위치로 임팩트 순간의 공 위치 추정
    • 소형 Transformer(매개변수 약 10만 개)
    • 물리 시뮬레이션 타구 2,400만 개로 학습, 실제 타구는 미사용

  4. 실제 타점과 비교

    • 고속 원본의 모든 프레임에서 공 궤적을 추적해 실제 타점 계산
    • 오차 = 추정 타점과 실제 타점 사이의 거리

검증하지 않은 것과 그 이유

  1. 고글(1인칭) 시점

    • 실제 타점을 알 수 있는 1인칭 고속 영상은 공개 자료에서 찾지 못함
    • 옆에서 촬영한 영상으로 대신 검증
    • 개발 절차 1단계(고글·고속 카메라 동시 촬영)⁠에서 확보 예정

  2. 타구음으로 임팩트 시각 검출

    • 공개 고속 영상에는 임팩트와 동기화된 소리가 없음
    • 타구음 검출은 선행연구 근거 [10] 보유 → 남은 과제인 타점 복원을 먼저 검증
    • ‘임팩트 시각을 알면’ 결과는 고속 원본의 시각에 0.5 ms 오차를 넣어 계산
    • 영상만으로도 대부분 10 cm 이내 → 타구음은 더 어려운 실제 고글 영상에 대비해 유지

  3. 카메라에서 공까지의 거리

    • 옆에서 촬영한 영상이라 화면 평면 안의 위치만 평가
    • 거리 추정은 공 크기를 이용하는 선행연구 [9] 근거

  4. 공 번짐(모션 블러)

    • 고속 영상은 노출이 짧아 번짐이 거의 없음
    • 실제 30 fps 촬영의 번짐은 1단계 데이터로 확인 필요

  5. 공 검출 모델의 추가 학습

    • 중계 영상용 공개 모델을 그대로 사용해 타구 개에서 검출 실패
    • 개발 절차 2단계에서 고글 영상으로 학습 예정

  6. 더 많은 타구와 별도 시험 데이터

    • 실제 타점을 계산할 수 있는 공개 영상이 적음
    • 후보 개 중 개 사용(영상 편, 대부분 연습 타구)
    • 검출 후처리 규칙도 이 타구들로 조정 → 새 영상에서는 정확도가 낮을 수 있음
